# Security policy

Thank you for helping keep Eleven Views Tools and its users safe.

## Reporting a vulnerability

Please report vulnerabilities privately. Do not open a public issue, pull request, or discussion.

- Email [dev@elevenviews.io](mailto:dev@elevenviews.io) with the subject `Security: Eleven Views Tools`.
- Or use GitHub's [private vulnerability reporting](https://github.com/Dongetabag/eleven-views-tools/security/advisories/new).

Include a description of the impact, reproduction steps or a proof of concept, the Eleven Views Tools version from Settings under About, and your macOS version. Please allow reasonable time for a reply and coordinated fix before public disclosure.

## Supported versions

Security fixes land on the latest released version. Please reproduce the issue on the latest release when practical.

## Scope

The most useful reports concern the integrity of the app, its update flow, local data, or misuse of granted macOS permissions. Issues in external services used by visible features, such as GitHub or Cloudflare, should be reported to those providers.
