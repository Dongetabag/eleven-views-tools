# Eleven Views Tools support

Eleven Views Tools is a free and open source macOS app maintained by Eleven Views. Start with the [documentation](#documentation) or the [troubleshooting guide](docs/TROUBLESHOOTING.md). For direct help, email [dev@elevenviews.io](mailto:dev@elevenviews.io).

## Report a bug

Use the app's Feedback window to open a pre-addressed email draft, email [dev@elevenviews.io](mailto:dev@elevenviews.io), or open a [GitHub issue](https://github.com/Dongetabag/eleven-views-tools/issues/new/choose). Include the Eleven Views Tools version from Settings under About, your macOS version, and clear steps to reproduce.

## Request a feature

Email [dev@elevenviews.io](mailto:dev@elevenviews.io) or use the [feature request form](https://github.com/Dongetabag/eleven-views-tools/issues/new/choose). Describe the problem you want solved and how it fits your work.

## Report a security issue

Do not post security vulnerabilities publicly. Email [dev@elevenviews.io](mailto:dev@elevenviews.io) with the subject `Security: Eleven Views Tools`, or use the repository's [private vulnerability report](https://github.com/Dongetabag/eleven-views-tools/security/advisories/new).
